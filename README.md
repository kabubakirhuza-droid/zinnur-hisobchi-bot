# 📊 Telegram Expense Bot (Учёт расходов с подтверждением по категориям)

Telegram-бот для учёта расходов в группах с пересылкой администратору для выбора категории и сохранения в **Google Sheets**.

---

## ⚡ Новая схема работы:

1. 👥 **Участник пишет в Telegram-группу:**
   ```text
   /hisob такси 20 000
   ```
2. 🤫 **В группе — полная тишина:** бот ничего не пишет в чат группы.
3. 📩 **Вам в личку (ID: `5709203608`) приходит уведомление с кнопками категорий:**
   * 💡 Svet uchun (Колонки A: Nomi, B: Narh)
   * 🔥 Gaz uchun (Колонки C: Nomi, D: Narh)
   * 🍲 Ovqat (Колонки E: Nomi, F: Narh)
   * 🛒 Kunlik xarajat (Колонки G: Nomi, H: Narh)
   * 💵 Oylik (Колонки I: Nomi, J: Narh)
   * 💳 Avans (Колонки K: Nomi, L: Narh)
   * ❌ Bekor qilish
4. 👆 **Вы нажимаете нужную категорию:**
   * Бот находит следующую свободную строку в соответствующих колонках этой категории (начиная со строки 3).
   * Записывает название расхода и сумму.
   * Обновляет сообщение в Telegram, показывая статус `✅ Google Sheets-ga saqlandi!`.

---

## 🚀 Запуск бота:

```bash
cd C:\Users\Hello\.gemini\antigravity\scratch\telegram-expense-bot

```
